<!-- 2. AWS Resource Access Manager (AWS RAM) -->
<h3 style="font-size:16px; font-weight:800; color:#0F172A; margin:24px 0 10px 0;">2. AWS Resource Access Manager (AWS RAM)</h3>
<p style="font-size:14px; color:#555555; margin-bottom:12px;">
<strong>Diễn giả:</strong> Long Huỳnh – Styl Solution
</p>

<p>AWS Resource Access Manager (AWS RAM) cho phép chia sẻ các tài nguyên được hỗ trợ (Subnet VPC, Transit Gateway, Route 53 Resolver Rules...) mà không yêu cầu mỗi tài khoản AWS con phải khởi tạo hạ tầng trùng lặp, giúp giảm thiểu chi phí dư thừa, đơn giản hóa cấu hình mạng và nâng cao hiệu quả quản trị tập trung.</p>

<!-- 3. AWS Pentest with AWS Continuum / Security Agent -->
<h3 style="font-size:16px; font-weight:800; color:#0F172A; margin:24px 0 10px 0;">3. AWS Pentest với AWS Continuum / Security Agent (AWS Pentest with AWS Continuum / Security Agent)</h3>
<p style="font-size:14px; color:#555555; margin-bottom:12px;">
<strong>Diễn giả:</strong> Thịnh Nguyễn – Styl Solution
</p>
<p>Phiên chia sẻ thứ ba giới thiệu phương pháp đánh giá an ninh hạ tầng tự động và kiểm thử thâm nhập (penetration testing) với sự hỗ trợ của các AI Security Agent, nhấn mạnh việc phát hiện sớm lỗ hổng ngay từ giai đoạn đầu của vòng đời phát triển phần mềm (SDLC).</p>

<h4 style="font-size:14.5px; font-weight:700; color:#171717; margin:18px 0 8px 0;">Bảo mật dịch chuyển trái (Shift-Left Security)</h4>
<p>Phương pháp tiếp cận Shift-Left Security được phân tích qua bốn bước kiểm soát an ninh:</p>
<ul>
<li>Rà soát và đánh giá an ninh trực tiếp trên mã nguồn hạ tầng Terraform (IaC Review).</li>
<li>Tích hợp các bước kiểm tra an ninh tự động vào Pull Request trên GitHub và GitLab.</li>
<li>Phát hiện sớm các cấu hình sai lệch và lỗ hổng tiềm ẩn trước khi tiến hành triển khai.</li>
<li>Sử dụng AI Security Agent để thực hiện kiểm thử thâm nhập tự động trong các môi trường SIT và UAT được cấp phép.</li>
</ul>

<h4 style="font-size:14.5px; font-weight:700; color:#171717; margin:18px 0 8px 0;">Quy trình đánh giá an ninh (Security Assessment Workflow)</h4>
<div class="minimal-formula-box" style="text-align: center; font-weight: 600; overflow-x: auto;">
Mã nguồn (Source Code) → Đánh giá an ninh (Security Review) → Môi trường thử nghiệm (Testing Env) → Xác thực bảo mật (Security Validation) → Triển khai Production
</div>

<!-- 4. Amazon Bedrock AgentCore -->
<h3 style="font-size:16px; font-weight:800; color:#0F172A; margin:24px 0 10px 0;">4. Amazon Bedrock AgentCore</h3>
<p style="font-size:14px; color:#555555; margin-bottom:12px;">
<strong>Diễn giả:</strong> Xuân An – Leader AWS Student Builder Group HCMUTE
</p>
<p>Nội dung phiên chia sẻ tập trung vào hai thành phần cốt lõi của Amazon Bedrock AgentCore: <strong>AgentCore Runtime</strong> và <strong>AgentCore Memory</strong>.</p>
<p>Các nội dung kỹ thuật liên quan bao gồm môi trường thực thi, quản lý ngữ cảnh, khả năng mở rộng và vận hành AI Agent trong môi trường Production.</p>

<h4 style="font-size:14.5px; font-weight:700; color:#171717; margin:18px 0 8px 0;">4.1. AgentCore Runtime</h4>
<p>AgentCore Runtime cung cấp môi trường thực thi được quản trị (managed runtime) chuyên biệt cho việc triển khai và vận hành các AI Agent. Các yếu tố kiến trúc quan trọng bao gồm:</p>
<ul>
<li>Khả năng cô lập phiên thực thi và phân tách khối lượng công việc của từng Agent (Agent execution & workload isolation).</li>
<li>Khả năng mở rộng hạ tầng tính toán tự động và linh hoạt (Infrastructure scalability).</li>
<li>Tối ưu hóa hiệu suất sử dụng tài nguyên điện toán (Resource utilization).</li>
<li>Đáp ứng các yêu cầu khắt khe khi đưa tác tử AI vào vận hành sản xuất thực tế (Production deployment requirements).</li>
</ul>

<h4 style="font-size:14.5px; font-weight:700; color:#171717; margin:18px 0 8px 0;">4.2. AgentCore Memory</h4>
<p>AgentCore Memory đảm bảo việc lưu trữ, quản trị ngữ cảnh hội thoại và thông tin liên quan xuyên suốt chuỗi tương tác nhiều lượt của AI Agent.</p>

<!-- 5. Kiro Crew -->
<h3 style="font-size:16px; font-weight:800; color:#0F172A; margin:24px 0 10px 0;">5. Kiro Crew – Tự động hóa và Phát triển phần mềm bằng AI (Kiro Crew – AI-Powered Development and Automation)</h3>
<p style="font-size:14px; color:#555555; margin-bottom:12px;">
<strong>Diễn giả:</strong> Khoa Kiều – Tech Lead, ACB &amp; Nghi Danh – AWS Community Builder
</p>
<p>Phiên chia sẻ cuối cùng khám phá cách các nhóm AI Agent (AI Agent Crew) phối hợp hỗ trợ chu trình phát triển phần mềm liên tục, rà soát mã nguồn tự động và kiểm tra trạng thái vận hành hệ thống.</p>

<h4 style="font-size:14.5px; font-weight:700; color:#171717; margin:18px 0 8px 0;">5.1. Khởi tạo Artifact trực quan (Artifact Generation)</h4>
<p>Phiên demo thực tế minh họa cách AI Agent tự động thu thập thông tin tuyển dụng việc làm, xử lý dữ liệu và trực tiếp sinh các báo cáo trực quan, biểu đồ thống kê tương tác ngay trong giao diện làm việc.</p>

<h4 style="font-size:14.5px; font-weight:700; color:#171717; margin:18px 0 8px 0;">5.2. Quản trị cửa sổ ngữ cảnh (Context Window Management)</h4>
<p>Các diễn giả phân tích các kỹ thuật tối ưu hóa khối lượng thông tin xử lý trong các luồng tương tác dài hạn qua hai khái niệm then chốt:</p>
<ul>
<li><strong>Auto Compact:</strong> Tự động nén và cô đọng ngữ cảnh cuộc trò chuyện khi dung lượng chạm ngưỡng giới hạn của Context Window.</li>
<li><strong>Context Breakdown:</strong> Phân tích chi tiết mức độ đóng góp của từng thành phần vào lượng token tiêu thụ, giúp định vị chính xác nguyên nhân phình to ngữ cảnh.</li>
</ul>

<h4 style="font-size:14.5px; font-weight:700; color:#171717; margin:18px 0 8px 0;">5.3. Quản lý bộ nhớ và Ranh giới an ninh (Memory Management &amp; Security Guardrails)</h4>
<p>Phiên chia sẻ nhấn mạnh tầm quan trọng của việc duy trì bộ nhớ chọn lọc và thiết lập các ranh giới bảo mật (Security Guardrails) nhằm ngăn chặn AI Agent:</p>
<ul>
<li>Tự ý xóa bỏ tài nguyên hoặc phá hủy hạ tầng đám mây khi chưa có ủy quyền rõ ràng.</li>
<li>Làm lộ lọt các khóa bí mật, API credentials và thông tin định danh nhạy cảm.</li>
<li>Thực hiện các thao tác sửa đổi cấu hình hệ thống ngoài phạm vi cho phép.</li>
<li>Thực thi các hoạt động có tính chất phá hoại hoặc nguy hiểm mà thiếu cơ chế kiểm soát của con người.</li>
</ul>

<h2 class="report-section-title">IV. Bài học cốt lõi (Key Takeaways)</h2>

<h3 style="font-size:15px; font-weight:700; color:#0F172A; margin:16px 0 8px 0;">
1. Bài học rút ra (Lessons Learned)
</h3>
<ul>
<li>Thấu hiểu tầm quan trọng của việc tối ưu hóa độ trễ phản hồi trong các hệ thống Voice AI để mang lại trải nghiệm đàm thoại tự nhiên.</li>
<li>Nhận thức rõ lợi ích của cơ chế chia sẻ tài nguyên tập trung và quản trị đám mây đa tài khoản (AWS RAM, AWS Organizations, SCPs).</li>
<li>Hiểu sâu sắc tầm quan trọng của việc tích hợp bảo mật sớm vào từng giai đoạn của vòng đời phát triển phần mềm (Shift-Left Security).</li>
<li>Nhận biết vai trò sống còn của môi trường thực thi (Runtime) và cơ chế quản trị bộ nhớ (Memory) đối với các AI Agent trong môi trường sản xuất.</li>
<li>Thấu hiểu sự cần thiết của các ranh giới bảo vệ an ninh (Security Guardrails) trong tự động hóa bằng AI để ngăn ngừa các tác vụ phá hoại hoặc trái phép.</li>
</ul>

<!-- 2. Practical Applications -->
<h3 style="font-size:15px; font-weight:700; color:#0F172A; margin:24px 0 8px 0;">
2. Khả năng vận dụng (Practical Applications)
</h3>
<ul>
<li><strong>Tối ưu hóa pipeline xử lý giọng nói:</strong> Nghiên cứu và ứng dụng mô hình cascade (STT → LLM → TTS) kết hợp bộ đệm thời gian thực và WebRTC vào các bài toán xây dựng trợ lý ảo tương tác hai chiều.</li>
<li><strong>Áp dụng chia sẻ tài nguyên an toàn:</strong> Vận dụng AWS RAM và Service Control Policies (SCPs) để thiết kế mô hình phân quyền và chia sẻ VPC Subnets trong các bài thực hành kiến trúc đa tài khoản.</li>
<li><strong>Tích hợp rà soát an ninh vào CI/CD:</strong> Áp dụng công cụ kiểm tra bảo mật mã nguồn IaC Terraform vào quy trình GitHub Actions cá nhân để phát hiện lỗ hổng cấu hình trước khi triển khai.</li>
<li><strong>Quản trị ngữ cảnh và guardrails cho AI Agent:</strong> Ứng dụng các kỹ thuật Auto Compact, phân tích token và Bedrock Guardrails khi phát triển các tác tử AI phục vụ hỗ trợ kỹ thuật và học tập.</li>
</ul>
