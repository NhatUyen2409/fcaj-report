# Week 7: AWS CloudFormation & Infrastructure as Code (26/10/2026 – 30/10/2026)

### Week 7 Objectives:
* Understand Infrastructure as Code (IaC).
* Learn AWS CloudFormation Templates and Stacks.
* Practice writing YAML and JSON templates.
* Deploy and manage AWS resources using CloudFormation.
* Explore AWS Systems Manager.

| Day | Task & Details | Start Date | Completion Date | Reference Materials |
