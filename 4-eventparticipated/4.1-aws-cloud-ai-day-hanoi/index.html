4. Main Topics & Technical Activities

4.1. Keynote and Agentic AI in Software Development

  • Keynote KEY001: Framed around solving ambitious technological challenges with cloud and AI primitives, highlighting three core directions: embedding AI agents in software pipelines, workload modernization, and defense-in-depth system security.
  • DVT205 / DVT203 (Building software like never before with agentic AI): Detailed how autonomous AI agents actively assist developers throughout the software lifecycle, from requirements analysis and code generation to automated testing and code review.
  • Transitioning from Demo to Production: Sessions AIM201 (From Demo to Deployment) and AIM301 (Scaling Multi-Agent Architectures) addressed practical hurdles in operationalizing AI agents; PRT301-S and PRT201-S emphasized human governance, reliability, and security guardrails.

4.2. Data Analytics and AI-Ready Infrastructure

  • Building AI-Ready Data Foundations: Sessions ANT202 and ANT211 established the critical necessity of authoritative data quality, cataloging, and low-latency access before deploying generative AI models.
  • Financial Services Industry Applications: ANT201 provided builder guidance on data-driven agents for FSI, complemented by ANT214 highlighting VPBank's experience scaling enterprise data on Amazon Redshift.
  • Unifying Siloed Data: ANT205 demonstrated cross-silo analytics using Amazon Quick Suite to derive complete business insights.

4.3. Application Modernization and Cloud Security

  • Internal Developer Platforms on EKS: DEV205 illustrated platform engineering at scale on Amazon EKS; DEV208 shared lessons from migrating NestJS workloads from EC2/PM2 to EKS powered by GitOps.
  • Monolith to Microservices: MAM203 outlined structured patterns for decomposing monolithic services onto EKS; AIM303 introduced AWS Transform AI Agent to automate the modernization of .NET and SQL Server workloads.
  • Workload Identity & AppSec: DEV401 explored advanced workload identity engineering; DVT305 showcased AWS Security Agent for proactive security from code to production; AIM203 addressed multi-tier defense in depth for agentic systems.

4.4. Cloud Operations and Cost Optimization

  • Storage Cost Optimization: DEV204, contributed by FCAJ, provided practical strategies for mastering Amazon S3 Storage Classes to eliminate unnecessary cloud expenditure.
  • Infrastructure Drift Remediation: DEV206 detailed multi-agent workflows for automated drift detection and correction in Terraform / IaC repositories.
  • Amazon Bedrock Spend Governance: DEV210 analyzed real-time cost control mechanisms and spend enforcement for enterprise Amazon Bedrock deployments at scale.
  • Observability in the GenAI Era: PRT203-S (Datadog) detailed monitoring strategies beyond traditional golden signals for non-deterministic AI workloads.
05

5. Knowledge & Lessons Learned

Key takeaways and technical insights acquired from the conference tracks:

Core DomainKey Insights & Engineering Principles
1. AI Reliability & SecurityDefine explicit boundaries, evaluation metrics, and verification mechanisms before deploying autonomous agents. Ensure strict guardrails against hallucinations, measure error rates, and mandate human-in-the-loop sign-off for state-modifying actions.
2. Data QualityAuthoritative, well-governed, and continuously refreshed data is the non-negotiable foundation for intelligent agents and analytics workloads.
3. Cloud ArchitectureAlign application modernization with concrete operational bottlenecks: leverage containerization (Amazon ECS/EKS) and declarative GitOps delivery to shorten release cycles and minimize deployment blast radius.
4. Monitoring & CostIntegrate operational observability and cost tracking into system architecture from day one. Apply lifecycle tiering to Amazon S3 data and continuously track token spend and inference latency on Amazon Bedrock.

Application to Nutrition E-Commerce Project

The architectural concepts gained from the conference directly inform our group capstone project, Nutrition E-Commerce:

  • Amazon Bedrock for Nutrition Extraction: Deploying foundation models on Amazon Bedrock to extract nutritional profiles and allergen data from food label uploads, accompanied by a verification UI where users confirm extracted information before database persistence.
  • S3 Storage Lifecycle Optimization: Applying automated S3 Lifecycle policies to product imagery and inspection documents, transitioning files from S3 Standard to S3 Standard-IA after 30 days and archiving historical compliance logs to S3 Glacier Flexible Retrieval after 90 days.
  • Microservices on Amazon ECS Fargate: Containerizing the core product catalog and nutritional recommendation APIs onto serverless AWS Fargate, paired with automated Application Load Balancer health checks for high service availability.
  • Identity & Cost Control: Enforcing least-privilege IAM roles and Workload Identity for containerized services, encrypting sensitive personal dietary records with AWS KMS, and implementing CloudWatch budget alerts on Amazon Bedrock invocation costs.
