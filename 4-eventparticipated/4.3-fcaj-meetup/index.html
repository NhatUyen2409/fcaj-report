FIRST CLOUD AI JOURNEY MEETUP

Exploring AWS Cloud, Cloud Security, and the Future of AI Agents

Location: 26th Floor, Bitexco Financial Tower, Ho Chi Minh City, Vietnam

01

I. Event Overview

The First Cloud AI Journey Meetup focused on five core technical domains: Voice AI, AWS Resource Access Manager (RAM), AI-assisted Penetration Testing, Amazon Bedrock AgentCore, and Kiro Crew.

Featured Speakers: Kiệt Trần, Long Huỳnh, Thịnh Nguyễn, Xuân An, Khoa Kiều, Nghi Danh

“The meetup gathered technology leaders, solutions engineers, and the AWS community in Vietnam, presenting technical lectures, live architecture demonstrations, and discussions on practical cloud and artificial intelligence applications in enterprise environments.”

The technical scope spanned real-time low-latency voice AI systems, secure cross-account cloud resource sharing, Shift-Left automated penetration testing, and production runtime environments and memory management for AI Agents.

02

II. Event Objectives

Core technical and architectural objectives established during the meetup:

  • Explore practical applications of AWS Cloud and Artificial Intelligence: Present cutting-edge cloud and AI services deployed directly into production systems.
  • Understand cloud resource sharing and security management: Analyze multi-account governance structured via AWS RAM, AWS Organizations, and SCPs.
  • Learn about Voice AI and AI Agent architectures: Examine real-time bidirectional conversational workflows and agentic execution engines.
  • Explore automated security testing and AI-powered development: Review Shift-Left Security methodologies and AI agents accelerating software engineering lifecycles.
  • Connect with the AWS engineering community: Provide an open technical exchange among architects, industry engineers, and builders.
03

III. Event Content & Technical Sessions

1. Hear, Think, Speak – Building a Vietnamese Voice-AI Contact Center on AWS

Speaker: Kiệt Trần – Revve AI

The session focused on three primary criteria in engineering production Voice AI systems: Response Accuracy, Low Latency, and Natural Conversational Experience.

The live demonstration showcased an AI-powered voice interview screening Cloud Engineer candidates in Vietnamese, engineered to reduce end-to-end response latency to approximately 1.8 seconds for smooth conversational turn-taking.

Voice AI Processing Workflow

Voice Input → Speech Recognition → AI Processing → Speech Generation → Voice Response
ComponentTechnical Function
HearReceive and process incoming user speech streams in real time.
ThinkInterpret requests, query contextual knowledge, and generate appropriate responses.
SpeakSynthesize generated text responses into natural spoken language for playback.

2. AWS Resource Access Manager (AWS RAM)

Speaker: Long Huỳnh – Styl Solution

The second session addressed secure cross-account resource sharing across multiple AWS accounts within an enterprise organization.

AWS Resource Access Manager allows supported resources (VPC Subnets, Transit Gateways, Route 53 Resolver Rules) to be shared without requiring duplicated infrastructure across sub-accounts, reducing overhead and streamlining centralized management.

Key Components

ComponentPrimary Function
AWS RAMEnables secure cross-account resource sharing across organizational accounts.
AWS OrganizationsSupports centralized hierarchy, multi-account governance, and consolidated billing.
IAM PoliciesDefines fine-grained access permissions for users and compute resources.
Service Control Policies (SCPs)Establishes organization-level permission guardrails and maximum permission boundaries.

3. AWS Pentest with AWS Continuum / Security Agent

Speaker: Thịnh Nguyễn – Styl Solution

The third session introduced automated infrastructure security assessment and penetration testing assisted by AI Security Agents, emphasizing early vulnerability identification during the software development lifecycle (SDLC).

Shift-Left Security

The Shift-Left Security methodology was outlined through four progressive validation checkpoints:

  • Reviewing Terraform infrastructure-as-code (IaC) definitions.
  • Integrating automated security checks into GitHub and GitLab pull requests.
  • Pinpointing misconfigurations and security exposures prior to deployment.
  • Deploying AI Security Agents to execute automated penetration tests in authorized SIT and UAT environments.

Security Assessment Workflow

Source Code → Security Review → Testing Environment → Security Validation → Production Deployment

4. Amazon Bedrock AgentCore

Speaker: Xuân An – Leader AWS Student Builder Group HCMUTE

The session focused on two primary architectural components of Amazon Bedrock AgentCore: AgentCore Runtime and AgentCore Memory.

Associated technical topics addressed execution environments, context management, scalability, and operating AI Agents within production workloads.

4.1. AgentCore Runtime

AgentCore Runtime provides a managed execution environment for deploying and operating AI Agents. Key architectural factors include:

  • Agent execution and workload isolation.
  • Elastic infrastructure scalability matching demand.
  • Optimized compute resource utilization.
  • Enterprise production deployment requirements.

4.2. AgentCore Memory

AgentCore Memory manages conversational context and persistent interaction states across multi-turn AI Agent workflows.

Memory TypeDescription
Short-term MemoryMaintains recent conversational context and immediate interaction history.
Long-term MemoryRetains persistent knowledge and preferences for cross-session retrieval.

5. Kiro Crew – AI-Powered Development and Automation

Speakers: Khoa Kiều – Tech Lead, ACB & Nghi Danh – AWS Community Builder

The final session explored how autonomous AI Agent groups support continuous software development, automated code inspection, and system status monitoring.

5.1. Artifact Generation

The live demonstration showed AI Agents collecting real-world job postings, parsing data streams, and generating interactive visual reports and analytical charts directly within the workspace.

5.2. Context Window Management

The speakers analyzed context window optimization techniques for long-running workflows via two core mechanisms:

  • Auto Compact: Automatically condenses conversation context as token usage approaches context limits.
  • Context Breakdown: Analyzes token distribution across components to isolate context expansion factors.

5.3. Memory Management & Security Guardrails

The presentation emphasized selective memory retention and establishing strict security guardrails preventing AI Agents from:

  • Deleting cloud infrastructure without explicit authorization.
  • Exposing sensitive secrets, access keys, or API credentials.
  • Performing unauthorized system or configuration modifications.
  • Executing destructive or high-risk operations without human oversight.
